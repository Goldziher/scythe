# Engine test-parity exemptions.
#
# Read by tools/integration-test-generator/tests/engine_test_parity.rs, which
# runs under `cargo test --workspace`.
#
# GH #196/#195: java.java.jinja and kotlin.kt.jinja each have one whole
# duplicated test program per SQL engine branch. An assertion added to one
# branch (almost always postgresql, the richest branch) reaches none of the
# others, and the branches drift apart silently -- the Redshift branches in
# particular ended up with fewer than half the postgresql branch's test
# functions. This file is the parity gate's ratcheting allowlist, modeled on
# coverage-exemptions.txt: it ratchets in BOTH directions and there is no
# tolerance mode.
#
#   * a (template, engine) branch missing a test function the postgresql
#     branch of the same template has, with no entry here, fails the build
#     (regression -- the drift got worse);
#   * an entry here for a test function the branch now DOES have also fails
#     the build (stale -- the gap was closed, delete the line).
#
# Format: <template>|<engine>|<test-function-name> : <reason>
#
# Two reason shapes appear below, and they mean different things:
#
#   - "no equivalent query exists in <engine>'s queries/*.sql fixture" --
#     the postgresql-only test calls a generated Queries method (an enum
#     parameter, or a nullable composite-column read for board #197) that
#     has no equivalent query defined for this engine at all. Closing this
#     requires designing a per-engine equivalent query, not copying an
#     assertion.
#   - "... but this engine's harness branch was never wired up to call it"
#     -- the underlying query already exists in this engine's queries
#     fixture (proven by grep against integration_tests/sql/<engine>/queries/)
#     and other engines' branches call it successfully. This is a real,
#     closeable coverage gap left for a follow-up change, not a structural
#     incompatibility. It is exempted here rather than silently passing so
#     the gap stays visible and deliberate, per GH #196/#195: "the point is
#     that the gap becomes visible and deliberate, not that a number goes up."
#
# Blank lines and lines starting with `#` are ignored.
